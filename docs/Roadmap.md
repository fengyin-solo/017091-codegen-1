# 知识配置平台 - 执行路线图

本文档为 **WHEN** 的权威来源，与 `docs/Requirements.md`（WHAT）配套使用。

---

## 技术栈与结构

- **前端**：`frontend-admin`（HTML + JavaScript + CSS + Tailwind CDN），纯静态展示，Mock 数据。
- **交付**：通过 `docker compose up` 启动，提供 Web 界面访问（localhost）。

---

## Phase 1：项目骨架与布局

- [x] **1.1** 初始化 `frontend-admin` 目录：入口 `index.html`，公共 CSS/JS，Tailwind CDN。
- [x] **1.2** 中后台布局：侧栏导航（商家知识 / 商家集合知识 / 行业知识 / 通用知识）、顶栏、主内容区。
- [x] **1.3** 路由或多页：四个知识类型对应入口页面或锚点，便于后续分模块开发。

**验收**：浏览器打开可见完整布局与导航，无报错。

---

## Phase 2：商家知识

- [x] **2.1** 商家知识列表页：支持按商家筛选（下拉/搜索），展示「商家 ID + 该商家下知识条数/列表」。
- [x] **2.2** 单商家下知识的增删改查：列表、新增、编辑、删除（含标准问、相似问、答案表单），Mock 数据。

**验收**：筛选商家、查看与增删改查知识流程可走通（前端交互 + 本地/Mock 数据）。

---

## Phase 3：商家集合知识

- [x] **3.1** 商家集合管理：列表、新建商家集合（名称 + 商家多选）、编辑集合内商家、删除集合。
- [x] **3.2** 商家集合知识：选择某集合后，在该集合下知识的列表与增删改查（标准问、相似问、答案），Mock 数据。

**验收**：新建/编辑集合、选择商家、在集合下管理知识流程可走通。

---

## Phase 4：行业知识

- [x] **4.1** 行业管理：列表、新增行业（二级行业选择：一级 + 二级）、编辑/删除行业。
- [x] **4.2** 行业知识：选择某行业后，在该行业下知识的列表与增删改查，Mock 数据。

**验收**：行业 CRUD、二级行业选择、行业下知识 CRUD 流程可走通。

---

## Phase 5：通用知识与黑名单

- [x] **5.1** 通用知识：列表与增删改查（标准问、相似问、答案），Mock 数据。
- [x] **5.2** 商家黑名单：黑名单列表、添加/移除商家（展示为不生效通用知识的商家），Mock 数据。

**验收**：通用知识管理 + 黑名单配置界面可用。

---

## Phase 6：Docker 与交付

- [x] **6.1** 使用 Nginx 或轻量静态服务将 `frontend-admin` 挂载为静态资源，`docker compose up` 可访问。
- [x] **6.2** 启动日志中输出访问地址（如 `Frontend Admin: http://localhost:xxxx`），README 更新。

**验收**：`docker compose up` 后可在本地浏览器访问中后台并完成上述各模块操作。

---

## 依赖关系

- Phase 1 为所有后续前置。
- Phase 2～5 可并行开发，但建议按 2 → 3 → 4 → 5 顺序便于复用组件与 Mock 结构。
- Phase 6 在 1～5 完成后收尾。
